# ذكّرني — Dhakkirni

تطبيق تذكير (وليس قائمة مهام). تكتب جملة عادية بالعربية أو الإنجليزية، فيفهم التطبيق **متى** أو **أين** يذكّرك.

| تكتب | ماذا يحدث |
|---|---|
| لما أخرج من الجامعة ذكرني أشتري خبز | إشعار «أشتري خبز» لحظة خروجك من نطاق الجامعة |
| لما أوصل البيت ذكرني أشحن الجوال | إشعار عند وصولك إلى البيت |
| ذكرني أتصل بأمي الساعة 5 | أقرب 5:00 قادمة |
| بكرة الساعة 8 الصبح ذكرني بالمحاضرة | غداً 8:00 ص |
| ذكرني بعد نص ساعة أطفي الغاز | بعد 30 دقيقة |
| remind me to buy milk when I leave the university | exit reminder |
| remind me at 6pm to go running | today 18:00 |

تحت مربع الكتابة تظهر معاينة فورية لما فهمه التطبيق قبل الحفظ.

## الأماكن
- إذا ذكرت مكاناً غير محفوظ (مثل «الجامعة») يسألك التطبيق: **«أنا فيه الآن — احفظه»** فيحفظ موقعك الحالي بهذا الاسم.
- أو احفظ أماكنك مسبقاً من قسم «أماكني» → «احفظ موقعي هنا».
- «الجامعة» و«جامعه» و«الجامعه» تُعتبر نفس المكان. النطاق الافتراضي 150 متراً.

## كيف يعمل
- **تذكير الوقت**: إشعار محلي مجدول (`expo-notifications`)، يعمل والتطبيق مغلق ودون إنترنت.
- **تذكير المكان**: Geofence من نظام التشغيل (`expo-location` + `expo-task-manager`) يوقظ التطبيق في الخلفية عند الخروج من النطاق أو الدخول إليه. لا يستهلك البطارية بتتبع مستمر.
- كل البيانات على الجهاز فقط (`AsyncStorage`).

## التشغيل
تذكيرات المكان تحتاج إذن الموقع **«السماح طوال الوقت»**، وهذا غير متاح في Expo Go، لذا يلزم Development Build:

```bash
npm install
npx expo run:android          # هاتف أندرويد متصل بـ USB (يحتاج Android SDK)
# أو بدون أدوات محلية:
npx eas-cli build -p android --profile development
npx expo start --dev-client
```

لتذكيرات الوقت فقط يمكن التجربة سريعاً عبر `npx expo start` وتطبيق Expo Go.

## الاختبارات
```bash
npm test          # اختبارات فهم الجمل (src/parser.test.ts)
npm run typecheck
```

## الملفات
- `src/parser.ts` — فهم الجملة: الوقت / المكان / نص التذكير.
- `src/engine.ts` — جدولة الإشعارات، تسجيل الـ Geofences، ومهمة الخلفية.
- `src/storage.ts` — حفظ التذكيرات والأماكن.
- `App.tsx` — الواجهة.
